# SmartATS AI

نظام إدارة توظيف مدعوم بالذكاء الاصطناعي — قيد البناء التدريجي.

## الحالة الحالية
- ✅ تسجيل دخول / إنشاء حساب (أول مستخدم = Admin تلقائياً)
- ✅ قاعدة البيانات (SQLite + SQLAlchemy): users, candidates, jobs, applications
- ✅ رفع سيرة ذاتية (PDF/DOCX/TXT) → استخلاص نص → استخلاص بيانات (Gemini إن توفر المفتاح، وإلا استخلاص أساسي بديل) → حفظ كمرشح
- ✅ إدارة المرشحين (عرض/بحث/إضافة يدوية)
- ✅ إدارة الوظائف (إضافة/عرض)
- ✅ مطابقة مرشحين ↔ وظيفة بدرجة مفسَّرة (Rule-based: مهارات + خبرة + موقع + تعليم)
- ⏳ القادم: OCR للسير الممسوحة ضوئياً، PPTX، pipeline التوظيف، المقابلات، الهيكل التنظيمي، التقارير

## لتفعيل الذكاء الاصطناعي (اختياري)
ضع مفتاحك في `.env`:
```
GEMINI_API_KEY=your-key-here
```
بدونه، سيعمل رفع السيرة الذاتية بشكل أساسي جداً (استخلاص بريد/هاتف فقط عبر regex) حتى لا يتوقف التطبيق.
لا يوجد حالياً أي حد لعدد الاستدعاءات (rate limit) أو تخزين مؤقت (caching) للنتائج — بقرار مقصود للتبسيط في هذه المرحلة.

## التشغيل

```bash
# 1. تثبيت المتطلبات
pip install -r requirements.txt

# 2. نسخ ملف البيئة وتعديله عند الحاجة
cp .env.example .env

# 3. تشغيل التطبيق
streamlit run app.py
```

أول مستخدم يتم تسجيله من شاشة "إنشاء حساب جديد" يصبح **Admin** تلقائياً.

## ملاحظات أمنية للمرحلة الحالية
- كلمات المرور تُخزَّن مُجزّأة (bcrypt) — ليست نص صريح.
- **لم يتم بعد** تشفير بيانات السير الذاتية أو تفعيل RBAC كامل أو حدود على استدعاءات AI — هذه مؤجلة بقرار صريح للتركيز على السرعة في هذه المرحلة، وسيتم تفعيلها لاحقاً.
